# REL1SW01 - One relay or two N-MOSFET

![REL1SW01A](/doc/gen/img/REL1SW01-top.png)

Universal module for bistable or monostable relays. The module is equipped with two N-MOSFETs that are designed for control by MCUs. The module's wiring allows you to use two transistors alone without the relay as a switch to GND.
